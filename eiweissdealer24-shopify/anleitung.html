1

Produkte importieren

Die Datei produkte-import.csv hat dir Claude im Chat geschickt. Speichere sie zuerst (iPad: Datei antippen → Teilen → In Dateien sichern).

  1. admin.shopify.com → Mein Shop → Produkte → Importieren
  2. Datei hinzufügen → produkte-import.csv auswählen
  3. Hochladen und Vorschau → Produkte importieren

Shopify lädt dabei die Produktbilder und schickt dir eine E-Mail, wenn alles fertig ist (ein paar Minuten). Die Bilder sind einheitlich: alle 1200 × 1200 Pixel, alle auf demselben schwarzen Hintergrund wie der Shop, das Produkt mittig mit leichtem Lichtsaum. So sehen Kollektionen, Suche und Produktseiten aus einem Guss aus. Alle Sorten und Größen eines Produkts haben den „ab“-Preis aus dem Original-Shop, denn die Preise einzelner Größen stehen dort nicht. Für die Präsentation passt das. Bevor echte Bestellungen möglich sind, müssen die Preise größerer Packungen nachgetragen werden. Der Lagerbestand wird nicht verfolgt, also ist nichts „ausverkauft“.

Theme-Kopie anlegen

Arbeite an einer Kopie, dann bleibt dein aktuelles Theme unverändert, bis alles fertig ist.

  1. Onlineshop → Themes → beim aktuellen Theme auf … → Duplizieren
  2. Bei der Kopie auf … → Code bearbeiten

12 Abschnitte einfügen

Für jede Datei unten wiederholst du diese vier Handgriffe:

  1. Im Code-Editor links den Ordner sections öffnen → + Neuen Abschnitt hinzufügen (bzw. „Datei hinzufügen“)
  2. Als Namen genau den Dateinamen eingeben, z. B. ed24-hero, ohne Endung. Fragt Shopify nach dem Typ, Liquid wählen → Fertig
  3. Den vorgegebenen Inhalt komplett löschen (alles markieren → löschen), dann hier Code kopieren tippen und dort einfügen
  4. Speichern → hier Eingefügt abhaken

Wichtig: Den Dateinamen exakt so schreiben wie hier angegeben, sonst finden sich die Abschnitte nicht gegenseitig. Eine Fehlermeldung beim Speichern heißt fast immer: Es wurde nicht der komplette Code eingefügt. Dann noch einmal alles löschen und neu einfügen.

  class Ed24Marquee extends HTMLElement {
    connectedCallback() {
      var self = this;
      this.track = this.querySelector('[data-ed24-track]');
      if (!this.track || window.matchMedia('(prefers-reduced-motion: reduce)').matches || !('IntersectionObserver' in window)) return;
      this.x = 0;
      this.lastY = window.scrollY;
      this.last = performance.now();
      this.observer = new IntersectionObserver(function (entries) {
        cancelAnimationFrame(self.raf);
        if (entries[0].isIntersecting) {
          self.half = self.track.scrollWidth / 2 || 1;
          self.last = performance.now();
          self.raf = requestAnimationFrame(function (t) { self.frame(t); });
        }
      });
      this.observer.observe(this);
    }

    disconnectedCallback() {
      if (this.observer) this.observer.disconnect();
      cancelAnimationFrame(this.raf);
    }

    frame(now) {
      var self = this;
      this.raf = requestAnimationFrame(function (t) { self.frame(t); });
      var dt = Math.min(0.05, (now - this.last) / 1000);
      this.last = now;
      var v = Math.abs(window.scrollY - this.lastY) / Math.max(dt, 0.001);
      this.lastY = window.scrollY;
      this.x = (this.x + (40 + Math.min(v, 4000) * 0.08) * dt) % this.half;
      this.track.style.transform = 'translate3d(' + -this.x + 'px,0,0)';
    }
  }

4

Startseite zusammenbauen

Bei der Theme-Kopie auf Anpassen tippen. Oben ist die Startseite ausgewählt.

  1. Vorhandene Abschnitte der Startseite, die du nicht brauchst (z. B. Bild-Banner, Diashow), ausblenden (Auge-Symbol) oder löschen
  2. In der Kopfzeile (Header-Bereich oben) Abschnitt hinzufügen → ED24 Topbar
  3. In der Vorlage (Startseite) die Abschnitte in dieser Reihenfolge hinzufügen und mit dem Griff ⠿ sortieren:
  1. ED24 Hero 3D ganz oben
  2. ED24 Produkt-Showcase direkt darunter
  3. ED24 Story
  4. ED24 Coaching-Panel hier endet die Effekt-Bühne
  5. Theme-Abschnitt Ausgewählte Kollektion (bei neueren Themes „Produktliste“) z. B. „Eigenmarke“ oder „Angebote“
  6. ED24 Ziele
  7. ED24 Marken (Physik)
  8. ED24 Laden & Team
  9. ED24 Laufschrift als letzter Abschnitt

Shop-Seite (alle Kategorien auf einer Seite, mit klebender Kategorie-Leiste): oben in der Seitenauswahl Seiten → Vorlage erstellen → Name shop → Abschnitt ED24 Shop-Übersicht hinzufügen und rechts unter „Kategorien“ die Kollektionen in der gewünschten Reihenfolge wählen. Danach Onlineshop → Seiten → Seite hinzufügen: Titel „Shop“, rechts Vorlage shop, sichtbar.

Hersteller-Seite: genauso eine Vorlage hersteller mit dem Abschnitt ED24 Hersteller anlegen und die Seite „Hersteller“ damit verknüpfen. Footer: im Footer-Bereich Abschnitt hinzufügen → ED24 Footer, rechts die drei Menüs wählen (Shop, Wissen & Team, Service & Rechtliches).

Reihenfolge 1–4 nicht unterbrechen. Hero, Showcase, Story und Coaching-Panel teilen sich eine Effekt-Bühne mit den schwebenden Produkten. Ein anderer Abschnitt dazwischen würde von ihr überdeckt.

Speichern nicht vergessen (oben rechts).

  • Fightwear nur zur Abholung: Fightwear gibt es bei Eiweissdealer24 nur im Laden. Unter Einstellungen → Versand und Zustellung zuerst Abholung vor Ort aktivieren. Dann ein benutzerdefiniertes Versandprofil „Fightwear“ anlegen, die Fightwear-Produkte hinzufügen und keine Versandtarife eintragen. So kann man sie nur abholen.
  • Mehr Filter in den Kollektionen: App Search & Discovery von Shopify installieren (kostenlos) → Filter → Filter hinzufügen: Marke (Anbieter), Produkttyp, Größe und Geschmack (Variantenoptionen), danach Speichern. Verfügbarkeit und Preis sind schon da.
